# Kvantiq Directory

A passive income online directory for hybrid quantum-classical and quantum-AI use cases, benchmarks, reproducibility, and challenges. Focused on the European quantum computing ecosystem, starting with Nordics + DACH.

## Stack

- **Framework:** Astro (static site generator)
- **Data:** JSON files in `data/`
- **Hosting:** Vercel free tier
- **Search:** Pagefind (client-side)
- **Cost:** $0/month
